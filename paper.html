1. Introduction 2. Model Architecture 3. Loss Formulation 4. Experiments & Summary
Document image restoration is a crucial pre-processing step for downstream Optical Character Recognition (OCR). Conventional methods typically rely on task-specific models engineered for distinct degradations. Although achieving reasonable performance on isolated tasks, these approaches fail to exploit the cross-task synergies and result in cumbersome multi-stage pipelines. To address this, we propose Uni-DocDiff, a unified generative paradigm that tackles multiple restoration tasks within a single model. By formulating restoration as a conditional denoising diffusion probabilistic model (DDPM), our approach leverages strong generative priors to reconstruct high-fidelity structures.
文件影像修復是下游光學字元辨識（OCR）系統極關鍵的前處理步驟。傳統方法通常依賴為特定退化現象量身打造的專屬模型。儘管在單一任務上表現尚可，但它們無法善用跨任務間的協同效應，導致系統管線臃腫。為此，我們提出了 Uni-DocDiff，這是一個統一的生成式典範，能在單一模型內處理多種修復任務。透過將修復建構為條件式去噪擴散機率模型（DDPM），本方法利用強大的生成先驗來重建高保真結構。

📍 段落批註：引言破題

邏輯角色確立從「多模型分工」轉向「單一基礎模型」的研究大方向。
亮點與巧思將「文件修復」的子任務統一歸納為「圖像生成」問題，名正言順引入 Diffusion。
The core architecture relies on a modified U-Net parameterized by $\theta$. Let $y \in \mathbb{R}^{H \times W \times 3}$ be the degraded condition image and $x_t \in \mathbb{R}^{H \times W \times 3}$ be the noisy latent state at timestep $t$. We concatenate $y$ and $x_t$ channel-wise as the input to the U-Net. Furthermore, we introduce a Task-Specific Prompt $p \in \mathbb{R}^{L \times C}$. This prompt is injected into the U-Net bottleneck layers via Cross-Attention, defined as $\text{Attention}(Q, K, V) = \text{softmax}(\frac{QK^T}{\sqrt{d}})V$, where the query $Q$ is derived from image features, and keys $K$/values $V$ from the prompt $p$.
核心架構依賴改良版 U-Net。假設 $y$ 為退化影像，$x_t$ 為時間步 $t$ 的含噪狀態。我們將 $y$ 和 $x_t$ 在通道維度上串接作為 U-Net 輸入。此外，我們引入了任務專屬提示（Task Prompt）$p$。此提示透過交叉注意力機制注入到 U-Net 瓶頸層，影像特徵作為查詢向量 $Q$，提示向量作為 $K$ 與 $V$。

⚙️ 架構解析：U-Net 與 Prompt

技術深度解析
張量維度：輸入為 (B, 6, H, W) (3通道原圖+3通道噪聲圖的 Early-fusion)。
Cross-Attention：允許空間特徵（Q）去動態查詢當前的任務指令（K,V），實現單一權重應對多種退化。
The model predicts the added Gaussian noise via $L_{simple} = \mathbb{E}_{x_0, \epsilon, t} \left[ \| \epsilon - \epsilon_\theta(x_t, t, y, p) \|_2^2 \right]$. To prevent edge blurring caused by standard diffusion, we introduce an auxiliary Spatial Gradient Penalty loss: $L_{grad} = \| \nabla x_0 - \nabla \hat{x}_0 \|_1$. The final objective is $L_{total} = L_{simple} + \lambda L_{grad}$.
模型透過 $L_{simple}$ 預測所添加的噪聲。為了防止標準擴散造成的邊緣模糊，我們引入空間梯度懲罰損失 $L_{grad}$，比較真實影像與預測影像的梯度差異。最終目標為 $L_{total} = L_{simple} + \lambda L_{grad}$。

🧮 損失函數：噪聲與梯度

技術深度解析
$L_{simple}$：擴散模型標準的 MSE 預測噪聲損失。
$L_{grad}$：引入 $\nabla$ (如Sobel) 與 L1 Norm。動機在於 MSE 易導致平滑，而 L1 梯度懲罰能促使模型產生銳利的文字邊緣，這對 OCR 提效至關重要。

Prevailing methods address distinct restoration tasks independently, leading to intricate systems and the incapability to harness multi-task learning synergies. To overcome this challenge, we propose DocRes, a generalist model that unifies five document image restoration tasks including dewarping, deshadowing, appearance enhancement, deblurring, and binarization. We propose a novel visual prompt approach called Dynamic Task-Specific Prompt (DTSPrompt). The DTSPrompt comprises distinct prior features extracted from the input image to instruct DocRes.
現行方法各自獨立處理不同的修復任務，導致系統複雜且無法發揮多任務學習的協同效應。為克服此挑戰，我們提出了 DocRes，這是一個能統一處理展平、去陰影、外觀增強、去模糊與二值化等五項任務的通用模型。我們提出了一種名為動態任務專屬提示（DTSPrompt）的視覺提示方法，該提示包含從輸入影像中萃取出的獨特先驗特徵，用以指導模型執行任務。

📍 段落批註：大一統模型的提出

邏輯角色點出碎片化模型的痛點，提出「Generalist Model（通用大模型）」的概念。
核心創新相比於用純文字當 Prompt，本文提出「視覺提示 (Visual Prompt)」— 從退化圖像本身提取任務相關特徵作為引導。
DocRes consists of a visual extractor and a restoration backbone. The visual extractor computes the DTSPrompt $P_{task}$ via basic image processing operations (e.g., Otsu's method for binarization prior). These visual prompts are then injected into the hierarchical features of the backbone. Let $F_l$ be the feature at layer $l$. The injection is achieved via Spatial Feature Modulation (SFM): $F'_l = F_l \odot \gamma(P_{task}) + \beta(P_{task})$, where $\gamma$ and $\beta$ are learnable projection layers that map the visual prompt to scaling and shifting parameters.
DocRes 包含一個視覺特徵萃取器與一個修復主幹網路。視覺萃取器透過基礎影像處理操作（例如使用 Otsu 演算法獲取二值化先驗）來計算出 DTSPrompt $P_{task}$。這些視覺提示接著被注入主幹網路的階層式特徵中。假設 $F_l$ 為第 $l$ 層的特徵，此注入過程是透過空間特徵調變（SFM）實現的：$F'_l = F_l \odot \gamma(P_{task}) + \beta(P_{task})$，其中 $\gamma$ 與 $\beta$ 是可學習的映射層，將視覺提示轉換為縮放與平移參數。

⚙️ 架構解析：DTSPrompt 與 SFM

技術深度解析
DTSPrompt：並非隨機初始化的 Embedding，而是具物理意義的先驗。例如：做去陰影時，Prompt 是背景光照圖；做二值化時，Prompt 是粗略的 Otsu 預測結果。
調變機制 (Modulation)：$\odot$ 代表 Element-wise 相乘。這是一種仿效 AdaIN (Adaptive Instance Normalization) 或 SPADE 的條件生成技巧，讓 Prompt 直接在空間維度上控制特徵的響應強度與偏移。
To train the unified network, we optimize the Charbonnier Loss: $L_{char} = \sqrt{\| \hat{I} - I_{gt} \|^2 + \epsilon^2}$ between the restored image $\hat{I}$ and the ground truth $I_{gt}$, where $\epsilon = 10^{-3}$ is a small constant for numerical stability. Unlike standard L1 loss, the Charbonnier loss is differentiable everywhere and provides robust gradients even for small errors, resulting in higher fidelity textures.
為了訓練這個統一網路，我們對修復影像 $\hat{I}$ 與真實標籤 $I_{gt}$ 之間計算 Charbonnier 損失進行最佳化：$L_{char} = \sqrt{\| \hat{I} - I_{gt} \|^2 + \epsilon^2}$，其中 $\epsilon = 10^{-3}$ 是為了數值穩定性的微小常數。與標準的 L1 損失不同，Charbonnier 損失在各處皆可微，且即使對微小的誤差也能提供穩健的梯度，從而產生更高保真度的紋理。

🧮 損失函數：Charbonnier Loss

技術深度解析
數學動機：L1 損失（絕對值）在 0 點不可微；L2 損失（平方）對離群值太敏感且在接近 0 時梯度消失。Charbonnier Loss 是一種平滑的 L1 損失，它結合了 L1 和 L2 的優點，在影像還原（如超解析度、去模糊）領域是公認能提升 PSNR 與視覺質量的首選 Loss。

  • Problem: 獨立修復任務缺乏通用性。
  • Method: 提取具體圖像先驗作為視覺 Prompt (DTSPrompt) 進行調變。
  • Conclusion: 單一模型即可達到 5 項任務的 SOTA。

優缺點點評

Current deep learning methods formulate document dewarping as a direct coordinate regression problem. However, deterministic regression models often struggle with complex, non-rigid deformations due to the highly nonlinear mapping space. We present DvD (Document dewarping via coordinates-based Diffusion), a generative paradigm. Instead of operating on RGB pixels, DvD treats the 2D backward mapping coordinates as the data distribution to be generated, effectively capturing the multimodal uncertainty of structural deformations.
目前的深度學習方法將文件展平視為直接的座標迴歸問題。然而，由於映射空間具有高度非線性，確定性的迴歸模型在處理複雜、非剛性變形時常遭遇困難。我們提出了 DvD（基於座標擴散的文件展平），這是一種生成式典範。有別於在 RGB 像素上操作，DvD 將 2D 反向映射座標視為待生成的資料分佈，有效地捕捉了結構變形的多模態不確定性。

📍 段落批註：重構問題域

邏輯角色打破「擴散模型只能生成圖像」的思維定勢，將其轉化為「座標映射生成器」。
關鍵概念「反向映射座標 (Backward mapping coordinates)」：決定展平後圖像上的每一個像素，應該去原變形圖上的哪個 (x, y) 座標抓取顏色。
The core of DvD is a conditional diffusion model defined over the coordinate space $C \in \mathbb{R}^{H \times W \times 2}$. During the forward process, we gradually add Gaussian noise to the ground truth coordinate map. In the reverse process, a noise predictor $\epsilon_\theta$ denoises the coordinate state. To provide structural context, we extract a multi-scale feature pyramid $\Phi(I)$ from the distorted image $I$, which is then injected into the U-Net via cross-attention layers at each denoising step.
DvD 的核心是一個定義在座標空間 $C \in \mathbb{R}^{H \times W \times 2}$ 的條件擴散模型。在正向過程中，我們逐漸將高斯噪聲加入到真實的座標映射圖中。在反向過程中，一個噪聲預測器 $\epsilon_\theta$ 對座標狀態進行去噪。為了提供結構上下文，我們從扭曲影像 $I$ 中萃取多尺度特徵金字塔 $\Phi(I)$，並在每次去噪步驟中透過交叉注意力層將其注入 U-Net。

⚙️ 架構解析：座標空間擴散

技術深度解析
張量變換：不同於圖像擴散的 3 通道 (RGB)，此處擴散的目標 $C_t$ 為 (B, 2, H, W) 的二維網格張量。
條件注入：$\Phi(I)$ 是條件（Condition）。網路在去噪座標時，必須看著扭曲的原始圖像特徵，才能知道文字行和邊界的走向，進而把座標「拉」回正確的網格位置。
The learning objective minimizes the discrepancy between the injected noise $\epsilon$ and the predicted noise on the coordinates: $L_{diff} = \mathbb{E}_{C_0, \epsilon, t} \left[ \| \epsilon - \epsilon_\theta(C_t, t, \Phi(I)) \|_2^2 \right]$. Furthermore, to ensure physical plausibility and prevent grid self-intersections, we impose a Grid Regularization Loss $L_{grid}$ based on total variation and local collinearity constraints on the predicted coordinate $C_0$.
學習目標是最小化注入噪聲 $\epsilon$ 與在座標上預測出之噪聲間的差異：$L_{diff} = \mathbb{E}_{C_0, \epsilon, t} \left[ \| \epsilon - \epsilon_\theta(C_t, t, \Phi(I)) \|_2^2 \right]$。此外，為確保物理上的合理性並防止網格自我交疊，我們對預測出的座標 $C_0$ 施加了基於全變差與局部共線約束的網格正則化損失 $L_{grid}$。

🧮 損失函數：噪聲與物理約束

技術深度解析
$L_{grid}$ 的必要性：如果預測的座標發生扭曲交叉（例如原本在左邊的點被映射到右邊點的右方），生成的圖像會出現「撕裂」或「重疊」。正則化項確保座標場是平滑且單調遞增的（保持拓樸結構）。

📍 段落批註：GAN 在修復的應用

邏輯角色早期（2020年左右）嘗試以對抗生成網路統一多種文件增強任務的重要先驅工作。
DE-GAN consists of two networks playing a minimax game. The Generator $G$ is an Encoder-Decoder architecture with skip connections (U-Net), mapping the degraded input $x$ to the clean output $y$. The Discriminator $D$ uses a PatchGAN architecture, which penalizes structure at the scale of patches. It takes the concatenation of $(x, y)$ or $(x, G(x))$ to classify whether the generated image is real or fake conditioned on the input.
DE-GAN 包含兩個進行極小化極大賽局的網路。生成器 $G$ 是具有跳躍連接的編碼器-解碼器架構（U-Net），將退化輸入 $x$ 映射至清晰輸出 $y$。判別器 $D$ 採用 PatchGAN 架構，在影像塊（Patch）的尺度上對結構進行懲罰。它接收 $(x, y)$ 或 $(x, G(x))$ 的串接張量，以在給定輸入的條件下，分類生成的影像為真或假。

⚙️ 架構解析：Pix2Pix 變體

技術深度解析
本質：DE-GAN 高度借鑒了經典的 Pix2Pix 圖像翻譯架構。
PatchGAN 的優勢：不是對整張圖片輸出單一的真假機率，而是輸出一個 $N \times N$ 的矩陣，評估每一個局部區塊（Patch）的真實度。這對保留文件的高頻細節（如文字筆畫）非常有效。
The objective of the conditional GAN is: $L_{cGAN}(G,D) = \mathbb{E}_{x,y}[\log D(x,y)] + \mathbb{E}_{x}[\log(1 - D(x, G(x)))]$. To guide the generator to produce exact matches with the ground truth, we add an L1 distance loss: $L_{L1}(G) = \mathbb{E}_{x,y}[\|y - G(x)\|_1]$. The final objective is $\arg \min_G \max_D L_{cGAN}(G,D) + \lambda L_{L1}(G)$.
條件 GAN 的目標函數為：$L_{cGAN}(G,D) = \mathbb{E}_{x,y}[\log D(x,y)] + \mathbb{E}_{x}[\log(1 - D(x, G(x)))]$。為了引導生成器產生與真實標籤精確匹配的結果，我們加入了 L1 距離損失：$L_{L1}(G) = \mathbb{E}_{x,y}[\|y - G(x)\|_1]$。最終的優化目標為極小極大化方程 $\arg \min_G \max_D L_{cGAN}(G,D) + \lambda L_{L1}(G)$。

技術深度解析
$L_{cGAN}$：確保生成的圖像在紋理和風格上像「真實文件」。

📍 段落批註：引入佈局語意

邏輯角色指出純像素級迴歸的盲點，論證「語意先驗（文字行必須是直的）」對幾何變換的重要性。
Our framework cascades a Layout Extraction Network (LEN) and a Deformation Prediction Network (DPN). LEN is an instance segmentation model predicting text line masks $M_{line}$. DPN takes both the image and the layout masks to regress the 2D displacement field $\mathcal{F} \in \mathbb{R}^{H \times W \times 2}$. 我們的框架串聯了佈局萃取網路（LEN）與變形預測網路（DPN）。LEN 是一個實例分割模型，負責預測文字行遮罩 $M_{line}$。DPN 同時接收影像與佈局遮罩，以迴歸出 2D 位移場 $\mathcal{F} \in \mathbb{R}^{H \times W \times 2}$。隨後，一個新穎的可微展平模組（DUM）利用 $\mathcal{F}$ 對原始影像進行採樣，生成平整的文件。

⚙️ 架構解析：雙階段級聯

技術深度解析
位移場 (Displacement Field) $\mathcal{F}$：記錄了影像中每一個像素點需要移動的 $(dx, dy)$ 向量。
DUM：本質上是 Spatial Transformer Network (STN) 中的 `grid_sample` 操作，它允許反向傳播梯度，使得整個管線可以進行 End-to-End 訓練。
In addition to the standard pixel-wise regression loss $L_{pix} = \|\mathcal{F} - \mathcal{F}_{gt}\|_1$, we formulate a Layout Perceptual Loss $L_{layout}$. By applying the predicted displacement $\mathcal{F}$ to warp the extracted text lines $M_{line}$, we penalize any curvature in the resulting lines, forcing them to be straight horizontally and vertically aligned: $L_{layout} = \sum_i (1 - \text{Linearity}(Warp(M^i_{line}, \mathcal{F})))$.
除了標準的像素級迴歸損失 $L_{pix} = \|\mathcal{F} - \mathcal{F}_{gt}\|_1$ 之外，我們設計了佈局感知損失 $L_{layout}$。透過將預測出的位移場 $\mathcal{F}$ 套用至萃取出的文字行 $M_{line}$ 上進行扭曲，我們對變形後文字行中的任何彎曲度施加懲罰，強制它們在水平及垂直方向上保持筆直與對齊：$L_{layout} = \sum_i (1 - \text{Linearity}(Warp(M^i_{line}, \mathcal{F})))$。

📍 段落批註：基於匹配的展平

邏輯角色將展平問題從「圖像迴歸」轉換為「跨域特徵點匹配（Image Matching）」，這在 Document AI 領域是獨特且魯棒的思路。
DocMatcher extracts line segments from both the camera image $I_c$ and the clean template $I_t$. These lines are represented as nodes in a Graph Neural Network (GNN). Using attention mechanisms, the GNN predicts matching scores $S \in [0, 1]^{N \times M}$ between $N$ camera lines and $M$ template lines. Once point correspondences are established from matched lines, we compute the Thin-Plate Spline (TPS) parameters $\Theta$ in a closed-form differentiable manner to warp the image.
DocMatcher 從相機拍攝圖 $I_c$ 與乾淨模板 $I_t$ 中雙雙萃取出線段。這些線段被表示為圖神經網路（GNN）中的節點。利用注意力機制，GNN 預測出 $N$ 條相機線與 $M$ 條模板線之間的匹配分數 $S \in [0, 1]^{N \times M}$。一旦由匹配線段建立了點對點的對應關係，我們便以封閉形式且可微的方式計算薄板樣條（TPS）參數 $\Theta$，進而對影像進行變形。

⚙️ 架構解析：GNN 與 TPS

技術深度解析
GNN 匹配：借鑒了 SuperGlue 等特徵匹配演算法。將線條的幾何與視覺特徵輸入 Transformer，學習跨域的對應關係。
TPS (Thin-Plate Spline)：一種經典的空間插值演算法。只要提供足夠的控制點（Control Points）匹配對，TPS 就能求出平滑的全局非線性變形場。由於矩陣運算是可微的，整個網路可端到端訓練。
The loss consists of two parts. The matching loss $L_{match}$ utilizes Focal Loss to supervise the predicted assignment matrix $S$ against the ground truth correspondences. The geometric loss $L_{grid} = \frac{1}{|V|} \sum_{v \in V} \| \mathcal{W}(v; \Theta) - v_{gt} \|_2$ measures the L2 distance between the TPS-warped grid points $\mathcal{W}(v; \Theta)$ and the true flat grid $v_{gt}$.
損失函數包含兩部分。匹配損失 $L_{match}$ 利用焦點損失（Focal Loss）來監督預測的分配矩陣 $S$ 與真實對應關係。幾何損失 $L_{grid} = \frac{1}{|V|} \sum_{v \in V} \| \mathcal{W}(v; \Theta) - v_{gt} \|_2$ 則計算經 TPS 扭曲後的網格點 $\mathcal{W}(v; \Theta)$ 與真實平整網格 $v_{gt}$ 之間的 L2 距離。

Focal Loss 的應用：由於多數線條是不匹配的（負樣本極多），Focal loss 能解決分配矩陣中正負樣本極度不平衡的問題。
$L_{grid}$：確保 TPS 算出來的變形場在整張圖的均勻控制點上是準確的，不僅僅在有文字線的地方準確。
