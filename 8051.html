宏觀導讀：把自己當作一顆 8051

學習 8051 的核心在於了解資源的匱乏。你只有 8 位元（一次只能算 0~255 的數字），極小的記憶體（128 Bytes RAM），以及幾根腳位。組合語言不是在寫邏輯，而是在做「搬運工」：把資料從記憶體搬到暫存器，用算術邏輯單元 (ALU) 運算後，再搬回記憶體或丟到 I/O 腳位上點亮 LED。
記住黃金法則：所有的資料流動，幾乎都必須經過「累積器 (Accumulator, A)」這個專屬工作台。

Ch 1-2 Microcontroller vs. Microprocessor

A Microprocessor (CPU) requires external RAM, ROM, and I/O ports to be functional. In contrast, a Microcontroller (MCU) contains a CPU, fixed amount of RAM, ROM, Timers, and I/O ports all embedded on a single chip. It is a System on a Chip (SoC). The classic 8051 has an 8-bit ALU, 4K Bytes of On-chip ROM, 128 Bytes of On-chip RAM, two timers, one serial port, and 4 I/O ports (each 8 bits wide).
重點譯文與精煉：
• 微處理器 (Microprocessor)： 像電腦的 Intel CPU，只有運算大腦，記憶體 (RAM/ROM) 和 I/O 都要外接，適合大數據處理。
• 微控制器 (Microcontroller, MCU)： 把 CPU、記憶體、定時器、I/O 腳位全部塞進「同一顆 IC 裡面」，就像一台微型電腦。8051 就是典型的 MCU。
• 8051 基礎體質： 它是 8 位元架構。內建 4KB 的 ROM（存程式碼）、128 Bytes 的 RAM（存變數）、以及 4 個 8-bit 的對外溝通腳位 (Port 0~3)。

① 學習目標

理解單晶片為什麼適合用在「嵌入式系統 (Embedded Systems)」(如遙控器、微波爐) 而非個人電腦。

② 記憶錨點

「MCU = 包含五臟六腑的微型一體機」

Ch 3 組合語言基礎與內部記憶體 (Registers & RAM)

The most widely used registers are A (Accumulator), B, R0-R7, DPTR, and PC. The instruction MOV dest, source copies data from source to destination. Never use `MOV R0, R1` (moving data between two generic registers is invalid in 8051). The PSW (Program Status Word) contains vital status flags like CY (Carry) and OV (Overflow). The Stack Pointer (SP) is an 8-bit register that points to the top of the stack. It defaults to `07H` upon reset.
重點譯文與精煉：
• 核心暫存器： `A` (最重要的累積器，幾乎所有運算都要靠它)、`B` (乘除法專用)、`R0~R7` (通用變數)、`DPTR` (16位元，用來指到 ROM 抓資料)、`PC` (程式計數器，指著下一行要執行的程式碼)。
• 搬移指令 MOV： 永遠是 `MOV 目的地, 來源` (右邊搬到左邊)。不能把資料直接從 R1 搬到 R2，一定要透過 A 轉手。
• 記憶體地圖 (128 Bytes RAM)：
　1. `00H~1FH`：分為 4 組 Bank，每組有 R0~R7 暫存器 (預設使用 Bank 0)。
　2. `20H~2FH`：可位元定址區 (Bit-addressable)，可以單獨控制某一個 Bit (如控制單顆 LED)。
　3. `30H~7FH`：一般用途的草稿區 (Scratch pad)，堆疊 (Stack) 通常在此。

🚨 簡報程式碼：期中考挖空熱區 (Stack & PSW)

考點分析： 考試極愛考 PUSH/POP 的順序（LIFO 先進後出），以及加法運算後的 PSW 旗標狀態（特別是 CY 進位與 AC 輔助進位）。

ORG 0000H1 ; 1. 挖空: 程式進入點必定是 0000H
MOV R6, #25H
MOV R1, #12H
PUSH 062 ; 2. 挖空: 陷阱！PUSH 不能接暫存器名稱(如 R6)，只能接記憶體直接地址(06H 代表 Bank0 的 R6)
PUSH 013 ; 3. 挖空: 存入 R1 的直接地址 01H
POP 014 ; 4. 挖空: LIFO (後進先出)，最後推入的 01H 要最先彈出來
POP 065 ; 5. 挖空: 再彈出 06H

; --- PSW 旗標考題 ---
MOV A, #38H
ADD A, #2FH6 ; 6. 挖空: # 字號代表立即數。 38H + 2FH = 67H
; 運算後：
; CY (Carry) = 0 (沒有超過 8 bits 的進位)
; AC (Aux Carry) = 1 (低半位元 8+F=17產生進位到高半位元)
; P (Parity) = 1 (67H = 01100111B，有 5 個 1，奇數所以 P=1)
END ; 程式結尾

① 解題思維

看到 `PUSH`/`POP` 的題目，一定要先在紙上畫一個堆疊。記住 `SP` 預設在 `07H`，每 `PUSH` 一次 `SP` 先加 1，再把資料放進去。彈出時順序必須完全顛倒！

② 致命陷阱

PUSH R0 是非法的！ 這點極常出現在選擇題或改錯題。組合語言規定堆疊指令只能使用「記憶體絕對位址 (Direct address)」，所以必須寫成 `PUSH 00H`。

Ch 4 分支與跳躍 (Branch Instructions)

Looping is typically done using DJNZ reg, label (Decrement and Jump if Not Zero). Conditional jumps include JZ (Jump if A is Zero), JNC (Jump if No Carry), and CJNE (Compare and Jump if Not Equal). Note that conditional jumps are all Short Jumps (relative offset -128 to +127 bytes). For subroutines, use LCALL (Long Call, 3-byte instruction targeting 64K space). It pushes the PC onto the stack. RET pops the stack back into the PC.
重點譯文與精煉：
組合語言沒有 `for` 迴圈，全靠「跳躍指令」改變 PC 的值來達成。
• 迴圈神指令 DJNZ： 讓某個暫存器減 1，如果不為 0 就跳回標籤處。用來寫計數迴圈超好用。
• 條件跳躍 JZ/JNZ/JC： 根據 A 是否為 0，或是 CY 旗標是否有進位來決定要不要跳躍。
• 呼叫副程式 LCALL/RET： 呼叫副程式時，CPU 會先把「下一行程式的地址 (PC)」推進去堆疊裡面保管。當副程式執行到 `RET` 時，再把地址從堆疊彈出來，回到主程式。

🚨 簡報程式碼：期中考挖空熱區 (Delay Loop)

考點分析： 雙層（或三層）延遲迴圈是必考題。考卷會挖空標籤跳躍的位置，測試你是否懂「內層先跑完，再跑外層」的邏輯。

; 產生延遲時間的副程式 (Nested Loop)
DELAY:
    MOV R2, #2001 ; 1. 挖空: 外層迴圈計數器 (最高只能寫 255 或 #0FFH)
AGAIN:
    MOV R3, #2502 ; 2. 挖空: 內層迴圈計數器
HERE:
    NOP ; 消耗 1 個機器週期 (Machine Cycle)
    DJNZ R3, HERE3 ; 3. 挖空: 內層要先扣到 0，所以跳回最近的 HERE 標籤
    DJNZ R2, AGAIN4 ; 4. 挖空: 內層跑完一輪後，外層扣 1，跳回 AGAIN 重新設定內層
    RET5 ; 5. 挖空: 副程式結束，必定使用 RET 返回主程式

① 解題思維

看到 `DJNZ` 就要聯想到迴圈。填空時，最下面的 `DJNZ` 往往跳回最上面的標籤（外層），而倒數第二個 `DJNZ` 跳回中間的標籤（內層），就像洋蔥一樣一層包一層。

② 記憶錨點

「DJNZ 是迴圈之王；CALL 必配 RET」

Ch 5 輸出入埠規劃 (I/O Port Programming)

The 8051 has 4 I/O ports: P0, P1, P2, and P3. Upon reset, all ports are configured as inputs (default logic 1). To use a port as an input, you must first write a 1 to it. Port 0 is open-drain and requires external 10K ohm pull-up resistors to function as a normal I/O port. Ports are bit-addressable (e.g., SETB P1.2 or CLR P2.7).
重點譯文與精煉：
• 輸入/輸出切換原理： 開機時預設腳位都是 High (1)。若要當作輸入讀取外接按鈕，必須先對該腳位寫入 '1'，這樣才不會因為內部電路把電位拉低而讀錯。
• P0 埠的缺陷 (極常考)： Port 0 的硬體設計是「開汲極 (Open-Drain)」，內部沒有上拉電阻。如果拿來接 LED 或按鈕，必須要在外部電路接 10KΩ 的上拉電阻，否則送不出 High 訊號。
• 位元操作： 用 `SETB` (設為 1) 或 `CLR` (清為 0) 來控制特定一根腳位。

🚨 簡報程式碼：期中考挖空熱區 (I/O Toggle & Switch)

考點分析： 考卷喜歡讓你實作「按下按鈕，LED 亮起」的邏輯。注意讀取腳位狀態前要先寫入 1，以及 `JB` (Jump if Bit = 1) / `JNB` (Jump if Bit = 0) 的使用。

; 讀取 P1.2 的開關狀態，並顯示在 P2.7 的 LED 上
    SETB P1.21 ; 1. 挖空: 關鍵！要把 P1.2 當輸入，必須先寫 1 給它
CHECK:
    JNB2 P1.2, TURN_ON ; 2. 挖空: 假設按鈕按下是接地(0)，JNB 代表「如果是 0 就跳」
    CLR P2.73 ; 3. 挖空: 沒按下時，關閉 LED (輸出 0)
    SJMP CHECK ; 無窮迴圈繼續檢查
TURN_ON:
    SETB P2.7 ; 按下時，打開 LED (輸出 1)
    SJMP4 CHECK ; 4. 挖空: 短跳躍，回到 CHECK 重新檢查

; --- I/O 反相(Toggle)考題 ---
TOGGLE:
    CPL5 P1.5 ; 5. 挖空: CPL (Complement) 是將腳位 0變1、1變0 的專用指令，常搭配方波產生
    ACALL DELAY
    SJMP TOGGLE

① 解題思維

看到「接上 Switch (開關)」的題目，反射動作就是尋找有沒有先設定 `SETB Px.x`！另外，題目常要求用 `CPL` 來產生特定頻率的方波。

② 記憶錨點

「讀入必先寫一，方波必用 CPL」

Ch 6 定址模式 (Addressing Modes)

1. Immediate: `#` directly follows the value (`MOV A, #25H`).
2. Register: Using Rn (`MOV A, R0`).
3. Direct: Using memory address directly (`MOV A, 40H`). SFRs (like P0, SP) must be accessed directly.
4. Register Indirect: Using `@` as a pointer (`MOV A, @R0`). R0 or R1 holds the RAM address.
5. Indexed: Used for reading lookup tables from ROM (`MOVC A, @A+DPTR`).
重點譯文與精煉：
• 立即 (Immediate) vs 直接 (Direct)： `#` 代表常數。`MOV A, #40H` 是把數字 40H 放進 A。沒有 `#` 的 `MOV A, 40H` 是把記憶體第 40 號抽屜的東西拿出來放進 A。
• 間接定址 (Indirect)： 用 `@R0` 或 `@R1` 把暫存器當作 C 語言的「指標」。要跑迴圈搬移連續記憶體資料 (Array) 時必定用這招。
• 索引定址 (Indexed)： 專門用來去 ROM (程式記憶體) 查表。因為 ROM 超過 256 Bytes，必須用 16-bit 的 DPTR 搭配 A 來當地址，指令是 `MOVC`。

🚨 簡報程式碼：期中考挖空熱區 (Block Transfer & Lookup)

考點分析： 記憶體區塊搬移（Block Transfer）是定址模式的集大成者。考題會要求你把一塊 RAM 複製到另一塊 RAM，這一定會挖空指標符號 `@` 與指標遞增指令 `INC`。

; 將 RAM 中 20H 開始的 10 個 Bytes，搬移到 60H 開始的位置
    MOV R0, #20H1 ; 1. 挖空: 來源指標的起點 (注意要加 #)
    MOV R1, #60H2 ; 2. 挖空: 目的指標的起點
    MOV R2, #10 ; 計數器設為 10
BACK:
    MOV A, @R03 ; 3. 挖空: 用間接定址法(@)，把 R0 指向的內容抓到 A (永遠靠 A 中轉)
    MOV @R14, A ; 4. 挖空: 把 A 的資料存進 R1 指向的地址
    INC5 R0 ; 5. 挖空: 來源指標往下一格移動 (Increment)
    INC6 R1 ; 6. 挖空: 目的指標往下一格移動
    DJNZ R2, BACK ; 迴圈判定

; --- 查表法考題 (讀取 ROM 資料) ---
    MOV DPTR, #MYDATA7 ; 7. 挖空: 設定 DPTR 指向資料表的起始標籤
    MOV A, #0
    MOVC8 A, @A+DPTR9 ; 8/9. 挖空: C 代表 Code(ROM)，這是唯一能讀取 ROM 內容的指令！
MYDATA: DB 'H', 'E', 'L', 'L', 'O'

① 解題思維

看到「搬移多筆資料 (Block Transfer)」的題目，一定會用到 @R0 或 @R1。如果題目是要把查表資料 (Lookup table) 送到某個 Port，就會看到 DPTR 和 MOVC A, @A+DPTR 連用的黃金組合！

② 語法陷阱

忘記加 # 字號： 這是初學者最常犯的錯。原本想寫 `MOV A, #05H` 讓 A 變成 5，結果漏打 # 寫成 `MOV A, 05H`，CPU 會跑去記憶體位址 `05H` 把裡面的垃圾資料讀進來！
