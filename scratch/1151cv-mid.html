▾

區域草圖 & 單連通域判別
▾
定義
單連通（Simply connected）：域內任意閉曲線均可在域內縮為一點（即「無洞」）。
HW3 Q2 — 五題判別
水平帶 $|\operatorname{Im}z|<1$ → 單連通 ✓（無洞）
環域 $1<|z|<2$ → 非單連通 ✗（有洞）
穿孔盤 $0<|2z-1|<2$ → 非單連通 ✗（有洞）
ℂ 排除非正實軸 → 單連通 ✓
橢圓外部 → 非單連通 ✗（無窮遠處有洞）
「有界」≠「單連通」；外部域的洞在無窮遠，故非單連通。原函數存在的前提之一是域為單連通。

極限不存在（方向性論證）
▾
方法
沿不同路徑 $z\to z_0$ 得到不同值 → 極限不存在。
HW1 Q5 — $\lim(\bar{z}/z)^2$ 在 $z\to0$
沿實軸 $z=x\to0$：$(x/x)^2=1$。沿對角線 $z=x+ix$：$\bar{z}/z=-i$，$(-i)^2=-1$。兩者不同，故極限不存在。 ∎
HW2 Q1 — $\lim\tan(a+iy)$ 當 $y\to\pm\infty$
$\tan z=-i(e^{2iz}-1)/(e^{2iz}+1)$，$z=a+iy$ 時 $e^{2iz}=e^{2ia-2y}$：$y\to+\infty$：$\to i$；$y\to-\infty$：$\to-i$。
D
CR 方程：解析性驗證 / 否定 / 極坐標版
▾
Cauchy–Riemann（直角坐標）
\[f=u+iv\text{ 在 }z_0\text{ 解析}\iff u_x=v_y,\;u_y=-v_x\quad(\text{偏導連續})\] 極坐標：$u_r=\tfrac{1}{r}v_\theta,\; v_r=-\tfrac{1}{r}u_\theta$
  1. 分離實部虛部寫出 $u(x,y)$、$v(x,y)$
  2. 計算四個偏導數 $u_x, u_y, v_x, v_y$
  3. 判斷 $u_x=v_y$ 且 $u_y=-v_x$ 是否在整個區域成立
HW1 Q6 — 驗證 $g(z)=(x^3-3xy^2)+i(3x^2y-y^3)$
$u_x=3x^2-3y^2=v_y$ ✓，$u_y=-6xy=-v_x$ ✓，全域成立，$g(z)=z^3$ 整函數。
HW1 Q7 — $|z|^2$ 不可微
$u=x^2+y^2$，$v=0$。$u_x=2x\ne v_y=0$ 除非 $x=0$，$u_y=2y\ne-v_x=0$ 除非 $y=0$。CR 僅在原點滿足，故不解析。
E
求諧函數共軛 $v$（已知 $u$）
▾
方法
用 CR：$v_y=u_x$，對 $y$ 積分得 $v+g(x)$；再用 $-v_x=u_y$ 決定 $g'(x)$，積分得 $g$。
例：$u=x^3-3xy^2$
$v_y=u_x=3x^2-3y^2$ → $v=3x^2y-y^3+g(x)$。
$-v_x=-6xy-g'(x)=u_y=-6xy$ → $g'(x)=0$ → $g=c$。
故 $f=z^3+ic$。
F
$|f|=$常數 → $f$ 常數；$\operatorname{Re}f=$常數 → $f$ 常數
▾
HW1 Q9 — $|f(z)|=1$，$f$ 整函數 → $f$ 常數
法1（Liouville）：$|f|\le1$ 有界 + 整函數 → Liouville → 常數。
法2（CR）：$u^2+v^2=c$，對 $x$ 偏微：$uu_x+vv_x=0$；代入 CR → $(u^2+v^2)u_x=0$ → $u_x=0$，同理 $u_y=v_x=v_y=0$ → 常數。
應用：$\operatorname{Re}f=c$ → $f$ 常數
$u=c$ → $u_x=u_y=0$；由 CR：$v_x=v_y=0$ → $f$ 常數。類似：$|e^f|=e^{\operatorname{Re}f}=$常數 → $\operatorname{Re}f=$常數 → 常數。

Liouville 定理（標準 + 加強版）
▾
標準 Liouville
整函數（全平面解析）且有界 ⇒ 常數。
HW4 Q1 — 加強版：$|f(z)|\le C|z|$ → $f(z)=Az$
對任意 $z_0$，取半徑 $R$ 的圓，對 $f''$ 用 Cauchy 估計： \[|f''(z_0)|\le\frac{2!\cdot C\max_{|z-z_0|=R}|z|}{R^2}\le\frac{2C(|z_0|+R)}{R^2}\xrightarrow{R\to\infty}0\] 故 $f''\equiv0$ → $f(z)=Az+B$；由 $|f(0)|\le C\cdot0=0$ 得 $B=0$。
廣義：$|f(z)|\le C|z|^n$ 整函數 → $f$ 為次數 $\le n$ 的多項式。考試常見：先對 $f'$ 或 $f''$ 用 Cauchy 估計，再令 $R\to\infty$ 迫使它為 $0$。

▾
定理
$f$ 在單連通域 $D$ 上解析 ⇒ $\int f\,dz=F(\text{end})-F(\text{start})$，閉合積分 $=0$。
HW3 Q1 — ★ 分支函數：$\int_{-1}^{1}z^i\,dz$
\[\int_{-1}^{1}z^i\,dz=\frac{(1+e^{-\pi})(1-i)}{2}\]
選主值分支（切線在負實軸）；路徑在上半平面，不穿越切線 ✓。

$F(1)=(1-i)/2$，$F(-1)=-e^{-\pi}(1-i)/2$，結果相減。

柯西積分公式（一階極點）＋部分分式拆解
▾
公式
\[\oint_C\frac{f(z)}{z-z_0}\,dz=2\pi i\,f(z_0)\quad(z_0\text{ 在 }C\text{ 內，}f\text{ 在 }C\text{ 及內部解析})\]
  1. 確認分母是一次式 $(z-z_0)$；多極點先拆部分分式
  2. 逐一確認每個 $z_k$ 是否在 $C$ 內

HW3 Q3 — 部分分式：$\oint_{|z|=2}(z-8)/(z^2-4z)\,dz$

留數定理（多個奇點）
▾
定理
\[\oint_C f\,dz=2\pi i\sum_k\operatorname{Res}(f,z_k)\quad(\text{對 }C\text{ 內所有奇點加總})\]
例

A
奇異點分類速查
▾
類型判別主要部分Res
可去奇點$\lim_{z\to z_0}f$ 有限無（$P=0$）$0$
$m$ 階極點$\lim(z-z_0)^m f\ne0$（$m$ 最小）$\sum_{k=1}^m b_k/(z-z_0)^k$$b_1$
本質奇點以上均否無限多負次項只能展開
速判例子（★易錯）
$\sin z/z$ → 可去（極限 $=1$，$\operatorname{Res}=0$）
$\sin z/z^2$ → 一階極點（$\operatorname{Res}=1$）
$\sin z/z^3$ → 二階極點（最低次 $z^{-2}$，$\operatorname{Res}=0$）

B
公式來源：從 Laurent 係數推導
▾
核心思路
留數 $b_1$ 是 $(z-z_0)^{-1}$ 的係數。要「讀出」它，就要讓 $b_1$ 移到常數項的位置，再取極限。
一階極點（$m=1$）的推導
Laurent 展開：$f(z) = \dfrac{b_1}{z-z_0} + a_0 + a_1(z-z_0)+\cdots$
兩邊乘 $(z-z_0)$： \[(z-z_0)f(z) = b_1 + a_0(z-z_0)+\cdots\] 右邊除 $b_1$ 外都含 $(z-z_0)$ 因子，取 $z\to z_0$： \[\boxed{\operatorname{Res}(f,z_0)=\lim_{z\to z_0}(z-z_0)\,f(z)}\]
$m$ 階極點的推導
展開：$f(z)=\dfrac{b_m}{(z-z_0)^m}+\cdots+\dfrac{b_1}{z-z_0}+a_0+\cdots$
Step 1：乘 $(z-z_0)^m$，消掉所有負冪次： \[(z-z_0)^m f(z) = b_m + \cdots + b_1(z-z_0)^{m-1} + a_0(z-z_0)^m+\cdots\] 現在 $b_1$ 在 $(z-z_0)^{m-1}$ 的位置。
Step 2：求 $m-1$ 次導，將 $(z-z_0)^{m-1}$ 以下的項全部消掉： \[\frac{d^{m-1}}{dz^{m-1}}[(z-z_0)^m f] = (m-1)!\,b_1 + (\text{含}(z-z_0)\text{的項})\] Step 3：取 $z\to z_0$，除以 $(m-1)!$： \[\boxed{\operatorname{Res}(f,z_0)=\frac{1}{(m-1)!}\lim_{z\to z_0}\frac{d^{m-1}}{dz^{m-1}}\bigl[(z-z_0)^m f(z)\bigr]}\]
一句話：乘掉分母 → $b_1$ 升到某冪次 → 求 $m-1$ 次導把它「翻」到常數項 → 除以 $(m-1)!$。
C
一階極點的留數（兩種公式）
▾
極限法
\[\operatorname{Res}(f,z_0)=\lim_{z\to z_0}(z-z_0)\,f(z)\]
$p/q'$ 公式（$f=p/q$，$q(z_0)=0$，$q'(z_0)\ne0$）
\[\operatorname{Res}(f,z_0)=\frac{p(z_0)}{q'(z_0)}\]
例
$\operatorname{Res}(e^z/(z^2+1),\,i)$：$q'=2z$，$q'(i)=2i$，$=e^i/(2i)$。
$\operatorname{Res}((5z-2)/(z(z-1)),\,0)$：$q'(0)=-1$，$=(-2)/(-1)=2$。
$\operatorname{Res}((5z-2)/(z(z-1)),\,1)$：$q'(1)=1$，$=3/1=3$。
先確認 $q'(z_0)\ne0$；若 $=0$ 則是高階極點，此公式失效。

$m$ 階極點的留數（導數公式）
▾
公式
\[\operatorname{Res}(f,z_0)=\frac{1}{(m-1)!}\lim_{z\to z_0}\frac{d^{m-1}}{dz^{m-1}}\bigl[(z-z_0)^m f(z)\bigr]\]

$g(z)=(z-0)^3\cdot e^z/z^3=e^z$，$(m-1)=2$：$g''(0)=1$，$\operatorname{Res}=1/2!\cdot1=\boxed{1/2}$。
$\oint e^z/z^3\,dz=2\pi i\cdot(1/2)=\pi i$。
★ 期中 Q8(b) 完整修正（原解有兩處錯誤）
$\oint_{|z|=2}e^z/(z(z+1)^3)\,dz$ — 圓內有兩個奇點：$z=0$（一階）和 $z=-1$（三階）。

原解錯誤：只看 $(z+1)^3$，漏掉 $z=0$ 且代入點算錯成 $f''(0)$。

Res$(f,0)$：$\lim_{z\to0}z\cdot e^z/(z(z+1)^3)=e^0/1^3=\boxed{1}$

Res$(f,-1)$：$g(z)=(z+1)^3\cdot e^z/(z(z+1)^3)=e^z/z$，求 $g''(-1)$： \[g'' = \frac{e^z(z^2-2z+2)}{z^3}\bigg|_{z=-1} = \frac{e^{-1}\cdot5}{-1}=-\frac{5}{e}\] $\operatorname{Res}(f,-1)=\frac{1}{2!}\cdot\left(-\frac{5}{e}\right)=\boxed{-\dfrac{5}{2e}}$

正確答案：$2\pi i\!\left(1-\dfrac{5}{2e}\right)$，不是 $\pi i$。
計算 $(m-1)$ 次導時乘積法則勿漏項；積分前必須清點 $C$ 內的全部奇點。

1
多奇點：找全部在 $C$ 內的奇點
症狀（期中 Q8b）：只看到 $(z+1)^3$，漏掉了 $z=0$。

正確做法：先列出被積函數所有的奇點，再逐一比較是否在 $C$ 內，全部在內的才計入 $\sum\operatorname{Res}$。

$e^z/(z(z+1)^3)$ 在 $|z|=2$：$z=0$（$|0|<2$ ✓）和 $z=-1$（$|-1|=1<2$ ✓）兩者都要算。
2
Laurent 展開直接求積分（期中 Q12）
方法：展開 $f(z)$ 在奇點附近的 Laurent 級數 → 讀 $(z-z_0)^{-1}$ 的係數 $b_1$ → 積分 $= 2\pi i\cdot b_1$。

$\oint_{|z|=1}\sin(1/z)\,dz$：展開 $\sin(1/z)=1/z-1/(3!z^3)+\cdots$，$b_1=1$，積分 $=2\pi i$。

不需要算任何極限或導數；展開完直接讀係數。
3
Liouville + Cauchy 不等式（期中 Q10）
題目：$f$ 整函數，$|f(z)|\le\sqrt{|z|}+1$ → 證明 $f$ 為常數。

Cauchy 不等式：對任意 $z_0$，取圓 $|z-z_0|=R$： \[|f'(z_0)|\le\frac{M_R}{R},\quad M_R=\max_{|z-z_0|=R}|f(z)|\] 由三角不等式：$|z|\le|z-z_0|+|z_0|=R+|z_0|$，故 \[M_R\le\sqrt{R+|z_0|}+1\] 代入： \[|f'(z_0)|\le\frac{\sqrt{R+|z_0|}+1}{R}=\frac{1}{\sqrt{R+|z_0|}-1}\cdot\frac{\sqrt{R+|z_0|}^{\,2}-1}{R}\xrightarrow{R\to\infty}0\] （更直接：$(\sqrt{R+|z_0|}+1)/R \sim 1/\sqrt{R}\to0$）

故對所有 $z_0$ 有 $f'(z_0)=0$ → $f$ 為常數（Liouville）。 ∎
