A 必會Question 2.6

緊緻性、極限點緊緻、序列緊緻

本節名詞定義

Open cover（開覆蓋）：若 \(A\subset X\)，一族 \(X\) 中的開集 \(\mathcal C=\{U_\alpha\}_{\alpha\in I}\) 滿足 \(A\subset\bigcup_{\alpha\in I}U_\alpha\)，則 \(\mathcal C\) 是 \(A\) 的 open cover。

Finite subcover（有限子覆蓋）：若存在有限多個 \(\alpha_1,\ldots,\alpha_n\in I\)，使 \(A\subset U_{\alpha_1}\cup\cdots\cup U_{\alpha_n}\)，則 \(\{U_{\alpha_1},\ldots,U_{\alpha_n}\}\) 是 finite subcover。

Compact（緊緻）：拓樸空間 \(X\) compact，表示 \(X\) 的每個 open cover 都有 finite subcover。子集 \(K\subset X\) compact，表示 \(K\) 配備 subspace topology 後 compact。

Limit point（極限點／聚點）：若 \(E\subset X\)，點 \(x\in X\) 是 \(E\) 的 limit point，表示每個 open neighborhood \(U\) of \(x\) 都滿足 \(U\cap(E\setminus\{x\})\ne\varnothing\)。

Limit point compact（極限點緊緻）：每個無限子集 \(E\subset X\) 都至少有一個 limit point in \(X\)。

Sequentially compact（序列緊緻）：\(X\) 中每個序列 \((x_n)\) 都存在收斂子序列 \((x_{n_k})\)，且其極限仍屬於 \(X\)。

First-countable（第一可數）：每個點 \(x\in X\) 都有 countable local base \(B_1,B_2,\ldots\)，使任意 open neighborhood \(U\) of \(x\) 都包含某個 \(B_n\)。

Second-countable（第二可數）：整個空間有可數 base \(\mathcal B=\{B_1,B_2,\ldots\}\)，每個 open set 都是這些 base elements 的聯集。

題目 2.6-1：compact implies limit point compact

題目：Show that if a topological space \((X,\mathcal U_X)\) is compact, then it is limit point compact.

證明想法說明：從任意無限子集 \(E\subset X\) 出發，反設它沒有 limit point。若每個點都不是 \(E\) 的 limit point，則每個 \(x\in X\) 都有一個 open neighborhood \(U_x\)，使 \(U_x\cap(E\setminus\{x\})=\varnothing\)，因此 \(U_x\cap E\subset\{x\}\)，所以 \(U_x\cap E\) 有限。這些 \(U_x\) 覆蓋整個 \(X\)，compactness 讓我們抽出有限子覆蓋。於是 \(E\) 被有限多個有限集合覆蓋，推出 \(E\) 有限，與假設矛盾。
考場模板：Let \(E\subset X\) be infinite. Suppose that \(E\) has no limit point. Then for each \(x\in X\), there exists an open neighborhood \(U_x\) of \(x\) such that \(U_x\cap(E\setminus\{x\})=\varnothing\). Hence \(U_x\cap E\subset\{x\}\), so \(U_x\cap E\) is finite. Since \(\{U_x:x\in X\}\) is an open cover of \(X\) and \(X\) is compact, there exist \(x_1,\ldots,x_n\in X\) such that \(X\subset U_{x_1}\cup\cdots\cup U_{x_n}\). Thus \(E\subset\bigcup_{i=1}^n(E\cap U_{x_i})\), a finite union of finite sets. Hence \(E\) is finite, contradiction. Therefore every infinite subset of \(X\) has a limit point, so \(X\) is limit point compact.

題目 2.6-2：first-countable Hausdorff 中，limit point compactness implies sequential compactness

題目：Show that if \((X,\mathcal U_X)\) is a first-countable Hausdorff space, then limit point compactness implies sequential compactness.

證明想法說明：要證明 sequential compactness，就從任意序列 \((x_n)\) 出發。若某個點出現無限多次，直接抽常值子序列。否則序列值域 \(E=\{x_n:n\in\mathbb N\}\) 是無限集合，由 limit point compactness 有 limit point \(x\)。first-countable 給 \(x\) 一組可數局部基底，將其改成遞減基底 \(C_k\)。因為 \(x\) 是 \(E\) 的 limit point，每個 \(C_k\) 都含有序列中尚未挑過的點，便可遞迴選 \(x_{n_k}\in C_k\)。遞減局部基底保證這個子序列收斂到 \(x\)。
考場模板：Let \((x_n)\) be a sequence in \(X\). If some value occurs infinitely many times, then a constant subsequence converges. Otherwise \(E=\{x_n:n\in\mathbb N\}\) is infinite. Since \(X\) is limit point compact, \(E\) has a limit point \(x\in X\). Since \(X\) is first-countable, choose a decreasing countable local base \(C_k\) at \(x\). Since \(x\) is a limit point of \(E\), each \(C_k\) meets \(E\setminus\{x\}\). Inductively choose \(n_k>n_{k-1}\) such that \(x_{n_k}\in C_k\). If \(U\) is any open neighborhood of \(x\), then \(C_K\subset U\) for some \(K\), and for \(k\ge K\), \(x_{n_k}\in C_k\subset C_K\subset U\). Hence \(x_{n_k}\to x\). Therefore \(X\) is sequentially compact.

題目 2.6-3：second-countable 中，sequential compactness implies compactness

題目：Show that if \((X,\mathcal U_X)\) is a second-countable topological space, then sequential compactness implies compactness.

證明想法說明：從任意 open cover \(\mathcal V\) 出發。second-countable 給可數基底，因此可把任意 cover 精煉成可數 cover \(G_1,G_2,\ldots\)。若此可數 cover 沒有 finite subcover，則對每個 \(n\) 選 \(x_n\notin G_1\cup\cdots\cup G_n\)。sequential compactness 給收斂子序列 \(x_{n_k}\to x\)。因為 \(G_j\) cover \(X\)，某個 \(G_m\) 含 \(x\)。由 \(G_m\) open，子序列最後會落入 \(G_m\)；但當 \(n_k\ge m\)，選點方式又保證 \(x_{n_k}\notin G_m\)，矛盾。
考場模板：Let \(\mathcal V\) be an open cover of \(X\). Since \(X\) is second-countable, let \(\mathcal B=\{B_1,B_2,\ldots\}\) be a countable base. Choose all basis elements \(B_j\) such that \(B_j\subset V\) for some \(V\in\mathcal V\). These selected \(B_j\)'s form a countable open cover of \(X\); enumerate them as \(G_1,G_2,\ldots\). Suppose this countable cover has no finite subcover. Then for each \(n\), choose \(x_n\notin G_1\cup\cdots\cup G_n\). By sequential compactness, there is a subsequence \(x_{n_k}\to x\). Since \(\{G_j\}\) covers \(X\), \(x\in G_m\) for some \(m\). Since \(G_m\) is open, eventually \(x_{n_k}\in G_m\). But if \(n_k\ge m\), then \(x_{n_k}\notin G_m\), contradiction. Hence the countable refinement has a finite subcover, and replacing each chosen basis element by the original \(V\in\mathcal V\) containing it gives a finite subcover of \(\mathcal V\). Thus \(X\) is compact.
A/B 混合Question 2.7

局部緊緻、Baire category theorem、單點緊緻化

本節名詞定義

Hausdorff / \(T_2\)：任意兩個相異點 \(x\ne y\) 都存在 disjoint open neighborhoods \(U,V\)，使 \(x\in U\)、\(y\in V\)、\(U\cap V=\varnothing\)。

Locally compact：常用考場版本是每個 \(x\in X\) 都有 open neighborhood \(W\)，使 \(\overline W\) compact。

Dense：\(A\subset X\) dense in \(X\) 表示 \(\overline A=X\)，等價於每個非空 open set 都與 \(A\) 相交。

Nowhere dense：\(A\) nowhere dense 表示 \(\operatorname{Int}(\overline A)=\varnothing\)。

Baire space：每個可數族 open dense sets 的交集仍 dense。Baire category theorem 常見版本：locally compact Hausdorff spaces 或 complete metric spaces 是 Baire spaces。

Compactification：\(Y\) 是 \(X\) 的 compactification，通常表示 \(Y\) compact Hausdorff，且 \(X\) 可嵌入為 \(Y\) 的 dense subspace。

One-point compactification：對 locally compact non-compact Hausdorff \(X\)，令 \(Y=X\cup\{\infty\}\)，包含 \(\infty\) 的基本開集形如 \(Y\setminus K\)，其中 \(K\subset X\) compact。

題目 2.7-1：局部緊緻 Hausdorff 空間中的縮小鄰域

題目：Prove that if \((X,\mathcal U_X)\) is a locally compact Hausdorff space, then for any point \(x\in X\) and any open neighborhood \(U\) of \(x\), there exists an open subset \(V\) with compact closure such that \(x\in V\subset\overline V\subset U\).

證明想法說明：先用 locally compact 在 \(x\) 周圍找到一個 compact closure 的小鄰域 \(W\)。再在 compact Hausdorff 的小空間 \(\overline W\) 裡，把 \(x\) 與不想碰到的部分 \(K=\overline W\setminus U\) 分離。這個分離會產生更小的 open set \(V\)，使 \(\overline V\) 仍留在 \(U\) 裡，且因為 \(\overline V\subset\overline W\)，所以 compact。
考場模板：Let \(x\in U\), where \(U\) is open. Since \(X\) is locally compact, choose an open neighborhood \(W\) of \(x\) such that \(\overline W\) is compact. Put \(K=\overline W\setminus U\). Then \(K\) is closed in the compact Hausdorff space \(\overline W\), and \(x\notin K\). Since compact Hausdorff spaces are normal, there is an open neighborhood \(O\) of \(x\) in \(\overline W\) such that \(\overline O^{\,\overline W}\cap K=\varnothing\). Choose \(V\) open in \(X\) with \(x\in V\subset O\cap W\). Then \(\overline V\subset\overline W\), so \(\overline V\) is compact, and \(\overline V\cap K=\varnothing\), hence \(\overline V\subset U\). Therefore \(x\in V\subset\overline V\subset U\).

題目 2.7-2：Baire category theorem

題目：State the Baire category theorem and provide a proof.

證明想法說明：在 locally compact Hausdorff 版本中，要證明可數個 open dense sets \(G_n\) 的交集仍 dense。取任意非空 open set \(U_0\)，遞迴選 \(U_n\)，讓 \(\overline{U_n}\) compact 且 \(\overline{U_n}\subset U_{n-1}\cap G_n\)。因為 \(G_n\) dense，所以每一步都有非空 open set 可選；因為 locally compact，可把它縮成 compact closure。最後 nested compact sets 的交集非空，交出的點同時落在 \(U_0\) 與所有 \(G_n\) 中。
考場模板：Baire category theorem: If \(X\) is a locally compact Hausdorff space, then the intersection of countably many open dense subsets of \(X\) is dense in \(X\). Let \(G_1,G_2,\ldots\) be open dense subsets and let \(U_0\) be a nonempty open set. Since \(G_1\) is dense, \(U_0\cap G_1\) is nonempty open. By local compactness, choose nonempty open \(U_1\) such that \(\overline{U_1}\) is compact and \(\overline{U_1}\subset U_0\cap G_1\). Inductively choose nonempty open \(U_n\) such that \(\overline{U_n}\) is compact and \(\overline{U_n}\subset U_{n-1}\cap G_n\). Then \(\overline{U_1}\supset\overline{U_2}\supset\cdots\) is a decreasing sequence of nonempty compact sets, so their intersection is nonempty. Any point in the intersection lies in \(U_0\cap\bigcap_{n=1}^{\infty}G_n\). Hence \(\bigcap_{n=1}^{\infty}G_n\) meets every nonempty open set and is dense.

題目 2.7-3：one-point compactification theorem 與 compact 原空間陷阱

題目：State the one-point compactification theorem. Is it still true that if the original topological space \(X\) is compact instead of locally compact, then the space \(Y\) obtained from the construction is a compactification of \(X\)?

證明想法說明：單點緊緻化是把 non-compact locally compact Hausdorff space 的所有「無限遠方向」壓成一點 \(\infty\)。若 \(X\) 原本 non-compact，則每個包含 \(\infty\) 的開集 \(Y\setminus K\) 都會和 \(X\) 大量相交，所以 \(X\) 在 \(Y\) 中 dense。若 \(X\) 原本已 compact，則 \(Y\setminus X=\{\infty\}\) 會成為開集或 \(X\) 會成為 closed，導致 \(X\) 不 dense，因此不符合 compactification 的通常定義。
考場模板：The one-point compactification theorem states that if \(X\) is a locally compact non-compact Hausdorff space, then \(Y=X\cup\{\infty\}\), with open sets consisting of the open sets of \(X\) and the sets \(Y\setminus K\), where \(K\subset X\) is compact, is a compact Hausdorff space and \(X\) is dense in \(Y\). Hence \(Y\) is a compactification of \(X\). If \(X\) is already compact, this construction does not give a compactification in the usual sense, because \(X\) is not dense in \(Y\). Indeed, \(X\) is compact and hence closed in the Hausdorff compactification setting; equivalently, the added point \(\infty\) is not in \(\overline X\). Thus the non-compact assumption is essential for \(X\) to be dense in the one-point compactification.

連通性、路徑連通性、有限與任意積空間

本節名詞定義

Separation：\(X=U\cup V\)，其中 \(U,V\) 是非空、互斥、相對開子集，則稱為 separation。

Connected：不存在 separation 的空間。等價地，唯一 clopen subsets 是 \(\varnothing\) 與 \(X\)。

Interval：\(I\subset\mathbb R\) 滿足若 \(a,b\in I\) 且 \(a

Path：continuous map \(\gamma:[0,1]\to X\)，若 \(\gamma(0)=p\)、\(\gamma(1)=q\)，稱為從 \(p\) 到 \(q\) 的路徑。

Path-connected：任兩點之間都有 path。path-connected 推出 connected，但反向不一定成立。

Product topology：有限積的基本開集為 \(U_1\times\cdots\times U_n\)。任意積 \(\prod_{\alpha\in I}X_\alpha\) 的基本開集只允許有限多個座標被 proper open sets 限制，其餘座標為整個 \(X_\alpha\)。

Tube lemma：若 \(Y\) compact，且 open set \(N\subset X\times Y\) 包含 \(\{x_0\}\times Y\)，則存在 open neighborhood \(W\) of \(x_0\)，使 \(W\times Y\subset N\)。

題目 2.8-1：\(A\subset B\subset\overline A\) 且 \(A\) connected，則 \(B\) connected

題目：Show that if \((X,\mathcal U_X)\) is a topological space and \(A\subset B\subset\overline A\) with \(A\) connected, then \(B\) is connected.

證明想法說明：連通集加上閉包中的點仍連通。反設 \(B\) 可分離成 \(C\cup D\)。由於 \(A\) connected，\(A\) 只能完全落在其中一邊，例如 \(C\)。但 \(D\) 是 \(B\) 中非空相對開集，且 \(D\subset B\subset\overline A\)，所以 \(D\) 應該碰到 \(A\)，與 \(A\subset C\)、\(C\cap D=\varnothing\) 矛盾。
考場模板：Suppose that \(B\) is not connected. Then \(B=C\cup D\) is a separation of \(B\). Since \(A\subset B\) and \(A\) is connected, \(A\) is contained in one side of the separation; assume \(A\subset C\). Since \(D\) is nonempty and open in the subspace \(B\), choose \(d\in D\). There is an open set \(O\subset X\) such that \(D=O\cap B\) near \(d\), so \(O\cap B\subset D\) is a neighborhood of \(d\) in \(B\). Since \(d\in B\subset\overline A\), every neighborhood of \(d\) meets \(A\). Hence \(D\cap A\ne\varnothing\), contradicting \(A\subset C\) and \(C\cap D=\varnothing\). Therefore \(B\) is connected.

題目 2.8-2：實數線非空子集 connected iff singleton 或 interval

題目：Prove that if \(E\) is a nonempty subset of \(\mathbb R\) with the usual topology, then \(E\) is connected iff \(E\) is either a singleton or an interval.

證明想法說明：若 \(E\) connected，卻有 \(a < c < b\)、\(a,b\in E\)、\(c\notin E\)，則 \(E\) 被 \(E\cap(-\infty,c)\) 與 \(E\cap(c,\infty)\) 分離。反向要證明 interval connected，通常用確界性質：若 interval 被分離，取一邊中低於另一邊的 supremum，利用相對開與 interval 性質推出該點不可能屬於任一邊，矛盾。
考場模板：Assume \(E\) is connected. If \(a,b\in E\), \(a < c < b\), and \(c\notin E\), then \(E=(E\cap(-\infty,c))\cup(E\cap(c,\infty))\) is a separation of \(E\), contradiction. Hence \(E\) has the interval property, so \(E\) is an interval, unless it is a singleton. Conversely, let \(E\) be an interval and suppose \(E=A\cup B\) is a separation. Choose \(a\in A\) and \(b\in B\) with \(a < b\). Let \(s=\sup(A\cap[a,b])\). By the interval property, \(s\in E\). If \(s\in A\), since \(A\) is relatively open, points of \(E\) slightly larger than \(s\) lie in \(A\), contradicting the definition of \(s\). If \(s\in B\), since \(B\) is relatively open, points of \(E\) slightly smaller than \(s\) lie in \(B\), again contradicting the definition of \(s\). Hence no separation exists, and \(E\) is connected.

題目 2.10-1：connected but not path-connected 的反例

題目： Give a counterexample of a space that is connected but not path-connected. Justify your answer with full details.

證明想法說明： 固定使用 topologist's sine curve。令 \(S=\left\{(x,\sin(1/x)):0<x\le1\right\}\)，並令 \(T=\overline{S}=S\cup(\left\{0\right\}\times[-1,1])\)。 因為 \((0,1]\) connected，且映射 \(x\mapsto(x,\sin(1/x))\) continuous， 所以 \(S\) connected。又因為 connected set 的 closure 仍 connected， 所以 \(T\) connected。另一方面，\(T\) 不是 path-connected。直觀上， 若有 path 從垂直線段 \(\left\{0\right\}\times[-1,1]\) 進入振盪曲線 \(S\)， 則當第一座標趨近 \(0^+\) 時，第二座標必須連續地跟隨 \(\sin(1/x)\) 的振盪； 但 \(\sin(1/x)\) 在 \(x\to0^+\) 時沒有極限，因此會違反 path 的連續性。

考場模板： Let \(S=\left\{(x,\sin(1/x)):0<x\le1\right\}\subset\mathbb{R}^2\), and let \(T=\overline{S}=S\cup(\left\{0\right\}\times[-1,1])\). Since \((0,1]\) is connected and the map \(x\mapsto(x,\sin(1/x))\) is continuous, \(S\) is connected. Since the closure of a connected set is connected, \(T\) is connected. We claim that \(T\) is not path-connected. Suppose, to the contrary, that there is a path \(\gamma:[0,1]\to T\) from a point of \(\left\{0\right\}\times[-1,1]\) to a point of \(S\). By continuity of the first coordinate, the path must contain points with positive first coordinate arbitrarily close to \(0\). On those points, the second coordinate must lie on the graph \(y=\sin(1/x)\). However, \(\sin(1/x)\) has no limit as \(x\to0^+\), contradicting the continuity of \(\gamma\). Hence no such path exists, so \(T\) is connected but not path-connected.

題目 2.10-2：有限乘積 connected

題目：Show that if \(X_j\) is connected for \(j=1,\ldots,n\), then \(\prod_{j=1}^nX_j\) is connected.

證明想法說明：先證兩個空間。固定一點 \((x_0,y_0)\)。對任意 \((x,y)\)，集合 \(X\times\{y_0\}\cup\{x\}\times Y\) 是兩個 connected sets 且交於 \((x,y_0)\)，因此 connected，並把共同骨架 \(X\times\{y_0\}\) 與每條垂直線連起來。整個 \(X\times Y\) 是這些有共同交集的 connected sets 的聯集，所以 connected。有限情形用 induction。
考場模板：It is enough to prove the case \(n=2\), then use induction. Fix \(y_0\in Y\). For each \(x\in X\), the sets \(X\times\{y_0\}\) and \(\{x\}\times Y\) are connected, and they intersect at \((x,y_0)\). Hence \(X\times\{y_0\}\cup\{x\}\times Y\) is connected. As \(x\) varies, these connected sets all meet the common connected set \(X\times\{y_0\}\), and their union is \(X\times Y\). Therefore \(X\times Y\) is connected. By induction, the finite product \(\prod_{j=1}^nX_j\) is connected.

題目 2.10-3：有限乘積 compact

題目：Show that if \(X_j\) is compact for \(j=1,\ldots,n\), then \(\prod_{j=1}^nX_j\) is compact.

證明想法說明：先證 \(X\times Y\)。給 open cover，固定 \(x\)，slice \(\{x\}\times Y\) compact，所以可被有限多個 cover elements 蓋住。tube lemma 把這個 slice 的有限覆蓋擴成一條管子 \(N_x\times Y\)。再用 \(X\) compact，從 \(\{N_x:x\in X\}\) 抽有限子覆蓋。合併所有有限批 cover elements，得到 \(X\times Y\) 的有限子覆蓋。
考場模板：We prove the case \(X\times Y\); the general finite case follows by induction. Let \(\mathcal U\) be an open cover of \(X\times Y\). For each \(x\in X\), the slice \(\{x\}\times Y\) is compact, so it is covered by finitely many members of \(\mathcal U\). Let their union be \(N_x\), an open set containing \(\{x\}\times Y\). By the tube lemma, there exists an open neighborhood \(W_x\) of \(x\) such that \(W_x\times Y\subset N_x\). The sets \(W_x\) cover \(X\). Since \(X\) is compact, choose \(x_1,\ldots,x_m\) with \(X\subset W_{x_1}\cup\cdots\cup W_{x_m}\). The finitely many members of \(\mathcal U\) used for the slices over \(x_1,\ldots,x_m\) cover \(X\times Y\). Hence \(X\times Y\) is compact, and finite products are compact by induction.

題目 2.12：任意乘積 connected

題目：Show that if \(X_\alpha\) is connected for \(\alpha\in A\), then \(\prod_{\alpha\in A}X_\alpha\) is connected.

證明想法說明：任意積不能直接用有限積 induction。固定 base point \(p=(p_\alpha)\)，考慮所有「只在有限多個座標與 \(p\) 不同」的點所成集合 \(D\)。每個有限座標變動部分都與有限乘積 connected 有關，且都含 \(p\)，所以 \(D\) connected。又 product topology 的基本開集只限制有限多個座標，因此每個非空基本開集都能找到一個只在有限座標改變的點，故 \(D\) dense。connected set 的 closure connected，整個乘積等於 \(\overline D\)，所以 connected。
考場模板：Choose a base point \(p=(p_\alpha)\in\prod_{\alpha\in A}X_\alpha\). Let \(D\) be the set of points which differ from \(p\) in only finitely many coordinates. For each finite \(F\subset A\), the subspace \(D_F=\{x:x_\alpha=p_\alpha\text{ for }\alpha\notin F\}\) is homeomorphic to the finite product \(\prod_{\alpha\in F}X_\alpha\), hence connected. All \(D_F\)'s contain \(p\), so \(D=\bigcup_FD_F\) is connected. Now \(D\) is dense in the product space: every nonempty basic open set restricts only finitely many coordinates, and we can choose a point in it which equals \(p\) outside those coordinates. Therefore \(\overline D=\prod_{\alpha\in A}X_\alpha\). Since the closure of a connected set is connected, the product is connected.
A 必會Question 2.13

商空間：由連續滿射得到同胚

本節名詞定義

Equivalence relation：關係 \(\sim\) 滿足 reflexive、symmetric、transitive。

Equivalence class：\([x]=\{y\in X:y\sim x\}\)。商集 \(X/\sim\) 是所有等價類的集合。

Quotient topology：自然投影 \(\pi:X\to X/\sim\) 下，\(O\subset X/\sim\) open iff \(\pi^{-1}(O)\) open in \(X\)。

Induced map：若 \(f:X\to Y\) 對等價類為 constant，即 \(x\sim x'\Rightarrow f(x)=f(x')\)，則可定義 \(\tilde f([x])=f(x)\)，但必須先證 well-defined。

Homeomorphism：bijective、continuous，且 inverse continuous 的函數。

題目 2.13：quotient by fibers is homeomorphic to target

題目：Show that if \(f:X\to Y\) is a continuous map from a compact space onto a Hausdorff space and \(x\sim_f x'\) iff \(f(x)=f(x')\), then there exists a homeomorphism \(\tilde f:X/\sim_f\to Y\).

證明想法說明：商空間把 \(f\) 送到同一點的所有 \(x\) 黏成同一個等價類。因此自然的函數是 \(\tilde f([x])=f(x)\)。證明順序固定是五步：定義、well-defined、bijective、continuous、compact-to-Hausdorff continuous bijection implies homeomorphism。最後一步要用 \(X/\sim_f\) compact，這來自 quotient map \(\pi:X\to X/\sim_f\) 是 continuous 且 \(X\) compact。
考場模板：Let \(\pi:X\to X/\sim_f\) be the quotient map. Define \(\tilde f:X/\sim_f\to Y\) by \(\tilde f([x])=f(x)\). This is well-defined because if \([x]=[x']\), then \(x\sim_f x'\), hence \(f(x)=f(x')\). The map \(\tilde f\) is surjective since \(f\) is onto. It is injective because \(\tilde f([x])=\tilde f([x'])\) implies \(f(x)=f(x')\), hence \(x\sim_f x'\), so \([x]=[x']\). Also \(f=\tilde f\circ\pi\). By the quotient topology, since \(f\) is continuous, \(\tilde f\) is continuous. Since \(X\) is compact and \(\pi\) is continuous, \(X/\sim_f\) is compact. Since \(Y\) is Hausdorff, a continuous bijection from a compact space to a Hausdorff space is a homeomorphism. Therefore \(\tilde f\) is a homeomorphism.
A/B 混合Question 3.1-

路徑同倫與基本群

本節名詞定義

Homotopy：\(f,g:X\to Y\) homotopic，表示存在 continuous \(H:X\times[0,1]\to Y\)，使 \(H(x,0)=f(x)\)、\(H(x,1)=g(x)\)。

Path-homotopy：兩條 path \(f,g:[0,1]\to X\) path-homotopic，表示存在 homotopy \(H\)，且端點固定：\(H(0,t)=f(0)=g(0)\)、\(H(1,t)=f(1)=g(1)\)。

Loop：base point \(p\) 處的 loop 是 \(f:[0,1]\to X\)，且 \(f(0)=f(1)=p\)。

Path concatenation：若 \(f(1)=g(0)\)，則 \(f*g\) 先走 \(f\) 再走 \(g\)。基本群乘法為 \([f][g]=[f*g]\)。

Fundamental group：\(\pi_1(X,p)\) 是 based loops at \(p\) 的 path-homotopy classes，運算為 concatenation，單位元素是 \([c_p]\)。

Simply connected：\(X\) path-connected 且 \(\pi_1(X,p)\) trivial，也就是每個 loop 都可縮到 constant loop。

Contractible：\(\operatorname{id}_X\) homotopic to a constant map。

Homotopy equivalence：存在 \(\varphi:X\to Y\)、\(\psi:Y\to X\)，使 \(\psi\circ\varphi\simeq\operatorname{id}_X\) 且 \(\varphi\circ\psi\simeq\operatorname{id}_Y\)。

題目 3.1-1：reparametrization of a path is path-homotopic to \(f\)

題目：Prove that any reparametrization of a path \(f\) is path-homotopic to \(f\).

證明想法說明：重參數化只是改變走路速度，不改變路徑幾何。若 \(g=f\circ\phi\)，其中 \(\phi(0)=0\)、\(\phi(1)=1\)，用直線插值 \((1-t)\phi(s)+ts\) 把參數 \(\phi(s)\) 連續變回 \(s\)。端點因為 \(\phi(0)=0\)、\(\phi(1)=1\) 被固定。
考場模板：Let \(g=f\circ\phi\) be a reparametrization of \(f\), where \(\phi:[0,1]\to[0,1]\) is continuous with \(\phi(0)=0\) and \(\phi(1)=1\). Define \(H(s,t)=f((1-t)\phi(s)+ts)\). Then \(H(s,0)=f(\phi(s))=g(s)\) and \(H(s,1)=f(s)\). Also \(H(0,t)=f(0)\) and \(H(1,t)=f(1)\), so endpoints are fixed. Hence \(g\) is path-homotopic to \(f\).

題目 3.1-2：基本群運算的 associativity 與 identity

題目：Show that the operation on \(\pi_1(X,p)\) is associative and that the path class of the constant map \(c_p\) is the identity element.

證明想法說明：\((f*g)*h\) 與 \(f*(g*h)\) 不是逐點相同，但只差路徑分段時間安排，所以在 path-homotopy class 中相同。constant loop \(c_p\) 表示在 base point 原地等待，\(c_p*f\) 與 \(f*c_p\) 都只是多了一段等待時間，也與 \(f\) path-homotopic。
考場模板：For loops \(f,g,h\) at \(p\), the paths \((f*g)*h\) and \(f*(g*h)\) traverse the same three loops in the same order, differing only by a reparametrization of \([0,1]\). By the reparametrization result, they are path-homotopic. Hence \(([f][g])[h]=[f]([g][h])\). Similarly, \(c_p*f\) and \(f*c_p\) differ from \(f\) only by inserting a constant waiting segment at \(p\), so both are path-homotopic to \(f\). Therefore \([c_p]\) is the identity element of \(\pi_1(X,p)\).

題目 3.1-3：path-connected 時，基本群與 base point 無關

題目：Prove that if \(X\) is path-connected, then \(\pi_1(X,p)\) is independent of the choice of base point \(p\).

證明想法說明：選一條 path \(\alpha\) 連接兩個 base points。任何 at \(p\) 的 loop \(f\)，都可用 \(\alpha\) 與反向路徑 \(\overline\alpha\) 包起來，變成 at \(q\) 的 loop。這給出 \(\pi_1(X,p)\to\pi_1(X,q)\) 的同構。反向同構用反向路徑。
考場模板：Let \(p,q\in X\). Since \(X\) is path-connected, choose a path \(\alpha\) from \(q\) to \(p\). Define \(\Phi:\pi_1(X,p)\to\pi_1(X,q)\) by \(\Phi([f])=[\alpha*f*\overline\alpha]\). This is well-defined because path-homotopic loops remain path-homotopic after concatenating fixed paths. It is a homomorphism. The inverse is given by \(\Psi([g])=[\overline\alpha*g*\alpha]\). Then \(\Psi\circ\Phi\) and \(\Phi\circ\Psi\) are the identity maps up to the standard homotopies \(\overline\alpha*\alpha\simeq c_p\) and \(\alpha*\overline\alpha\simeq c_q\). Hence \(\pi_1(X,p)\cong\pi_1(X,q)\).

題目 3.1-4：fundamental group is a topological invariant

題目：Show that the fundamental group is a topological invariant.

證明想法說明：若 \(h:X\to Y\) 是 homeomorphism，則每個 loop \(f\) 可送成 \(h\circ f\)。這定義 induced homomorphism \(h_*\)。因為 \(h^{-1}\) 也連續，所以 \((h^{-1})_*\) 是反向同構。因此同胚空間的基本群同構。
考場模板：Let \(h:X\to Y\) be a homeomorphism and \(p\in X\). Define \(h_*:\pi_1(X,p)\to\pi_1(Y,h(p))\) by \(h_*([f])=[h\circ f]\). This is well-defined: if \(f\simeq g\) by a path-homotopy \(H\), then \(h\circ H\) is a path-homotopy from \(h\circ f\) to \(h\circ g\). The map \(h_*\) is a homomorphism since it preserves concatenation. Since \(h^{-1}\) is continuous, \((h^{-1})_*\) is the inverse of \(h_*\). Hence \(h_*\) is a group isomorphism. Therefore the fundamental group is invariant under homeomorphism.

題目 3.1-5：simply connected 的等價敘述

題目：Prove that if \(X\) is path-connected, then \(X\) is simply connected iff any two paths in \(X\) with the same initial and terminal points are path-homotopic.

證明想法說明：若 simply connected，任意 loop 都可縮成常值。兩條同端點 path \(f,g\) 的差異可以組成 loop \(f*\overline g\)，它可縮掉，所以 \(f\) 與 \(g\) 同倫。反向更直接：任意 loop \(f\) 與 constant loop \(c_p\) 有相同起終點，所以 path-homotopic，故基本群 trivial。
考場模板：Assume \(X\) is simply connected. Let \(f,g\) be paths with the same initial point \(a\) and terminal point \(b\). Then \(f*\overline g\) is a loop at \(a\), hence it is path-homotopic to \(c_a\). By concatenating this homotopy with \(g\), we obtain \(f\simeq g\) relative to endpoints. Conversely, suppose any two paths with the same endpoints are path-homotopic. If \(f\) is any loop at \(p\), then \(f\) and the constant loop \(c_p\) have the same initial and terminal point. Hence \(f\simeq c_p\). Thus every loop is null-homotopic, so \(\pi_1(X,p)\) is trivial. Since \(X\) is path-connected, \(X\) is simply connected.

題目 3.1-6：product space 的 fundamental group

題目：Show that \(\pi_1(\prod_{j=1}^nX_j,(p_1,\ldots,p_n))\cong\prod_{j=1}^n\pi_1(X_j,p_j)\).

證明想法說明：loop in product space 等同於每個座標各有一條 loop。用投影 \(\pi_j\) 把 product loop 分解成座標 loop，定義 \(\Phi([f])=([\pi_1\circ f],\ldots,[\pi_n\circ f])\)。反過來，給每個座標 loop \(f_j\)，可組成 product loop \(f(t)=(f_1(t),\ldots,f_n(t))\)。兩邊互逆。
考場模板：Define \(\Phi:\pi_1(\prod_{j=1}^nX_j,p)\to\prod_{j=1}^n\pi_1(X_j,p_j)\) by \(\Phi([f])=([\pi_1\circ f],\ldots,[\pi_n\circ f])\), where \(p=(p_1,\ldots,p_n)\). This is well-defined because composing a path-homotopy with each projection gives a path-homotopy in each coordinate. It is a homomorphism since projections preserve concatenation. It is surjective: given loops \(f_j\) at \(p_j\), define \(f(t)=(f_1(t),\ldots,f_n(t))\). Then \(\Phi([f])=([f_1],\ldots,[f_n])\). It is injective because if all coordinate loops are null-homotopic, the coordinate homotopies combine into a product homotopy. Hence \(\Phi\) is a group isomorphism.

題目 3.1-7：contractible 的三個等價條件

題目：Prove that the following are equivalent: \(X\) is contractible; \(X\) is homotopy equivalent to a one-point space; each point of \(X\) is a deformation retract of \(X\).

證明想法說明：contractible 就是整個空間可以縮到一點，因此自然等價於和單點空間同倫等價。若有 deformation retract 到每個點，當然可縮；若有 homotopy from \(\operatorname{id}_X\) to a constant map at \(x\)，這個 homotopy 就是把 \(X\) deformation retract 到 \(\{x\}\) 的核心資料。
考場模板：If \(X\) is contractible, then there is a homotopy from \(\operatorname{id}_X\) to a constant map \(c_x\). Let \(r:X\to\{x\}\) be the constant map and \(i:\{x\}\to X\) the inclusion. Then \(r\circ i=\operatorname{id}_{\{x\}}\) and \(i\circ r=c_x\simeq\operatorname{id}_X\), so \(X\) is homotopy equivalent to \(\{x\}\). Conversely, if \(X\) is homotopy equivalent to a one-point space, then \(\operatorname{id}_X\) is homotopic to a constant map, so \(X\) is contractible. Finally, a deformation retraction of \(X\) onto a point is precisely a homotopy from \(\operatorname{id}_X\) to the constant map at that point while fixing the point. Hence the three conditions are equivalent.

題目 3.1-8：homotopy equivalence induces isomorphism on \(\pi_1\)

題目：Show that if \(\varphi:X\to Y\) is a homotopy equivalence, then for any \(p\in X\), the induced homomorphism \(\varphi_*:\pi_1(X,p)\to\pi_1(Y,\varphi(p))\) is a group isomorphism.

證明想法說明：若 \(\varphi\) 是 homotopy equivalence，有 homotopy inverse \(\psi\)。因此 \(\psi\circ\varphi\simeq\operatorname{id}_X\)、\(\varphi\circ\psi\simeq\operatorname{id}_Y\)。誘導到基本群後，\(\psi_*\circ\varphi_*\) 與 \(\varphi_*\circ\psi_*\) 分別等於 identity，所以 \(\varphi_*\) 有反函數。嚴格版本要處理 base point 在 homotopy 下可能移動，但考場通常寫出主要同構邏輯即可。
考場模板：Let \(\psi:Y\to X\) be a homotopy inverse of \(\varphi\). Then \(\psi\circ\varphi\simeq\operatorname{id}_X\) and \(\varphi\circ\psi\simeq\operatorname{id}_Y\). Passing to fundamental groups, we get \(\psi_*\circ\varphi_*=(\psi\circ\varphi)_*=(\operatorname{id}_X)_*\) and \(\varphi_*\circ\psi_*=(\varphi\circ\psi)_*=(\operatorname{id}_Y)_*\), up to the standard base-point-change isomorphisms when necessary. Hence \(\psi_*\) is the inverse of \(\varphi_*\), and \(\varphi_*\) is a group isomorphism.
