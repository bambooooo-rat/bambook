# 歡迎來到 Bambook

Bambook 是我整理學習資源、課程教材、文章筆記與小工具的地方。這裡的內容主要給學生使用，也歡迎朋友或偶然點進來的陌生訪客自由瀏覽。

如果你是為了課程而來，可以先從上方的「教材」進入。那裡會依照科目整理講義、課本、投影片、練習題與其他學習資源。部分資料只是彙整索引，方便大家快速找到需要的內容；實際使用時仍請尊重原作者與出版單位的著作權。

如果你只是想看看我最近整理了什麼，可以到「文章」。那裡會放一些比較像筆記、心得或補充說明的文章。文章內容不一定都很正式，有些可能是課程補充，有些可能只是我整理問題時留下的思路。

「其他」則收納一些獨立的小工具，例如指令查詢、地理練習、成績相關頁面或其他實驗性網頁。這些工具不一定和課程教材直接相關，但希望它們在需要的時候能剛好派上用場。

這個網站是靜態網站，公開放在 GitHub Pages 上。也就是說，它不需要登入、不需要伺服器資料庫，也不會替使用者儲存個人資料。你看到的大多數內容都只是瀏覽器直接載入的 HTML、CSS、JavaScript、Markdown 或 PDF 檔案。

## 如何使用

- 想找課程資料：點選上方「教材」，再選擇對應科目。
- 想閱讀筆記或網站說明：點選「文章」。
- 想使用小工具：點選「其他」。
- 想回到首頁：點左上角的 Bambook 標誌。

如果你發現連結失效、檔案錯放、內容需要修正，或有任何建議，歡迎透過頁尾的聯絡資訊告訴我。這裡會慢慢整理、慢慢長大；如果它剛好幫你省下一點找資料的時間，那它就很值得存在了。
