# ε-δ 語言：極限的嚴謹定義

「$x$ 趨近於某個值」聽起來很直覺，但如果追問「趨近」到底要多接近，這個說法其實相當模糊。這種模糊在實際計算極限時，很容易讓人自相矛盾。

考慮這個極限：

$$\lim_{x \to 2} \frac{(x+5)(x-2)}{x-2}$$

我們可能會說「$x$ 只是趨近於 $2$，並不等於 $2$」，因此把分子分母的 $(x-2)$ 消去，得到 $\lim_{x\to2}(x+5)$；但緊接著又說「既然 $x$ 無限趨近於 $2$，那就直接代入 $2$」，算出 $5+2=7$。同一個 $x$，一下子不等於 $2$、一下子又等於 $2$，這種明顯的矛盾說明我們需要一套更精確的語言來描述「趨近」——這就是「$\varepsilon-\delta$ 語言」。

## 一個排隊的比喻

想像一群人排隊走向目標 $B$。要怎麼精確描述「這群人是往 $B$ 走，而不是往別的地方走」？一個直觀的想法是：$B$ 附近應該會聚集越來越多人。具體來說，我們可以以 $B$ 為圓心畫一個半徑 $\varepsilon$ 的圈，只要給定夠小的 $\varepsilon$，就一定能找到隊伍裡的一個編號範圍，使得編號落在這個範圍內的人，位置也會落在圈子裡。

把這個比喻搬到函數上：排隊編號看作自變數 $x$，人的位置看作函數值 $f(x)$。給定任意小的函數值誤差範圍 $\varepsilon$，我們希望總能找到一個對應的自變數範圍 $\delta_\varepsilon$，使得只要 $x$ 落在這個 $\delta_\varepsilon$ 範圍內（但 $x \neq x_0$），函數值 $f(x)$ 就會落在 $\varepsilon$ 範圍內。

## 正式定義

> 給定函數 $f(x)$ 以及定義域內的任意值 $x_0$，我們說
> $$\lim_{x \to x_0} f(x) = L$$
> 等價於：
> $$\forall \varepsilon > 0,\ \exists\, \delta_\varepsilon > 0 \text{ s.t. } 0 < |x-x_0| < \delta_\varepsilon \ \Rightarrow\ |f(x)-L| < \varepsilon$$

這個定義裡藏著四個步驟：先任意給定一個 $\varepsilon$；接著找到與之對應的 $\delta_\varepsilon$；再假設 $x$ 滿足 $0<|x-x_0|<\delta_\varepsilon$；最後由此推導出 $|f(x)-L|<\varepsilon$。每次用 $\varepsilon-\delta$ 語言證明一個極限，都要照這四步走一遍。

實際操作時有個常見的順序問題：給定 $\varepsilon$ 之後，我們通常沒有線索一眼看出 $\delta_\varepsilon$ 該長怎樣。所以慣用的做法是先把 $\delta_\varepsilon$ 空著，直接去化簡 $|f(x)-L|$，等看清楚它跟 $|x-x_0|$ 的關係之後，再反過來決定 $\delta_\varepsilon$ 要怎麼選。

## 一個示範

> **例.** 用 $\varepsilon-\delta$ 語言證明 $\displaystyle \lim_{x\to2}(2x+5)=9$。
>
> 先不管 $\delta_\varepsilon$，直接化簡目標式子：
> $$|f(x)-L| = |(2x+5)-9| = |2x-4| = 2|x-2|$$
>
> 現在很清楚了：只要 $2|x-2|<\varepsilon$，也就是 $|x-2|<\varepsilon/2$，結論就會成立。於是我們選 $\delta_\varepsilon = \varepsilon/2$。
>
> **證明.** 給定 $\varepsilon>0$，選 $\delta_\varepsilon=\varepsilon/2$。若 $0<|x-2|<\delta_\varepsilon$，則
> $$|f(x)-L| = |(2x+5)-9| = 2|x-2| < 2\delta_\varepsilon = \varepsilon.$$
> 因 $\varepsilon$ 為任意，故 $\displaystyle \lim_{x\to2}(2x+5)=9$。$\blacksquare$

整個證明的關鍵，就是那句「先不管 $\delta_\varepsilon$，直接化簡 $|f(x)-L|$」——化簡的結果 $2|x-2|$ 直接告訴我們該怎麼選 $\delta_\varepsilon$，證明本身反而是最後才補上去的形式。

## 為什麼不用每次都這樣做

看到這裡難免會擔心：以後每算一個極限，都要重新走一次這四個步驟嗎？好消息是不用。只要先確認一些基本函數（多項式、指數、對數、三角函數等）的極限值等於它們的函數值，再搭配極限對加減乘除、複合運算「拆得開」的特性，大多數極限就可以直接代入計算，不必每次都回到 $\varepsilon-\delta$ 定義。這套語言真正派上用場的時機，反而是在需要嚴謹說明「為什麼」某個極限成立、或是處理一些沒辦法直接代入的複雜函數的時候。
